# KX Studio Android — LLVM ARMv7 native runtime development

KX Studio is an Android IDE for the KX v0.21 compiler. The Android application targets **32-bit ARM (armeabi-v7a)** and uses Kotlin for the UI plus C++17/JNI for the compiler and native runtime.

## Implemented

- Native Android project with Kotlin UI and C++17/JNI.
- KX lexer/parser, semantic analysis, typed-IR validation, and LLVM IR emission.
- Target triple: armv7a-linux-androideabi24.
- Source editor with Android document-picker open/save.
- Compile and Run work on a background executor so the UI remains responsive.
- LLVM C API runtime interface using **MCJIT**: parse generated LLVM IR, initialize LLVM's ARM target, JIT-compile for the running ARMv7 Android process, invoke main, and capture printf output for the editor.
- GitHub Actions cross-builds LLVM 18.1.8 for Android armeabi-v7a, stages the LLVM C headers and shared library, and packages them with libkxstudio.so.

## Native execution status

The Run path is being upgraded from a deliberately disabled placeholder to LLVM MCJIT execution. The MCJIT runtime is only enabled when the APK contains the ARM-enabled libLLVM.so. A frontend-only local build without that library will show that the LLVM runtime is unavailable.

**Do not treat the new runtime as device-verified until the LLVM Android build succeeds and a real KX program has been executed on an ARMv7 Android device.** Android JIT memory permissions and runtime symbol resolution must be confirmed on-device.

This milestone uses LLVM MCJIT for in-process native execution. **LLD-based AOT output to a standalone libkx.so is not implemented yet.** The current native execution route is JIT, not an LLD-linked APK plugin.

## Build with GitHub Actions

1. Open the repository's **Actions** tab.
2. Run or inspect **Build KX Studio ARMv7 APK with LLVM**.
3. Wait for all LLVM cross-build, APK build, and packaging checks to pass.
4. Download the **KX-Studio-ARMv7-LLVM-debug** artifact and install app-debug.apk on a compatible ARMv7 Android device.

The workflow builds LLVM in CI, so the developer does not need to install an NDK or LLVM toolchain on the phone.

## Local build requirements

- JDK 17
- Android SDK
- Android NDK 27.2.12479018
- CMake 3.22.1
- Gradle 8.9
- The staged ARMv7 libLLVM.so and LLVM C headers generated by the CI workflow

```kx
    i32 y = 2;
    print(x + y);
    return 0;
}
```

```text
42

[Native ARM execution completed; exit code 0]
```
